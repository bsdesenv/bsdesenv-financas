O que vai acontecer

Uns 3 minutos. São 4 passos.

  1. Avançado ›

    Autorizar o instalador

    O Google avisa “app não verificado”. É esperado. Toque em Avançado e depois em Acessar. Marque Selecionar tudo.

  2. Ligar a API do Apps Script

    Uma chave para ligar, uma vez só. A tela abre sozinha e o instalador espera você voltar.

  3. Finanças

    Escolher o nome da planilha

    Ela nasce no seu Drive, com o nome que você quiser. Só você tem acesso.

  4. Instalar

    Instalar

    Toque em Instalar e espere uns 20 segundos. No fim, o link do seu app aparece na tela.

Na primeira vez que abrir o app, o Google pede para autorizar de novo. É normal: o desenvolvedor é você, porque o app roda na sua conta.

Por que o aviso aparece?

O instalador ainda não passou pela verificação do Google, que é um processo longo e feito para empresas. Por isso o aviso aparece. O código é aberto: você pode conferir tudo o que ele faz.

O código é aberto: qualquer pessoa pode ler e conferir o que ele faz.
